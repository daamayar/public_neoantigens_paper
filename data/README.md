# Simulation data

This directory is empty in the repository. The production trajectories are
~50 GB  and are distributed through Zenodo.

Unpack the Zenodo archives here, or set `PHLA_DATA_ROOT` to wherever you put
them. Either way the layout must be

```
<data root>/<complex>/rep_<n>/...
```

See [../docs/DATA.md](../docs/DATA.md) for the archive contents.
